# 第二章案例素材来源

本章是CJ的Golden Laksa实拍与AI制作学习记录，整理于2026年10月1日。

- original-cut.mp4：由CJ提供、女儿帮忙拍摄的手机实拍剪成25秒（拍摄者由CJ于2026年10月1日说明）；画面未做AI环境、人物衣服或碗材质修改，已有剪接配乐，不等于相机原始连续文件。
- final-ad.mp4：用户选定的Genjutsu版本画面，加本轮CapCut华语男声、简单配乐与轻转场音效。Genjutsu用于真人入口镜头；其余画面来自已完成的AI参考生成和Seedance汤浪转场，再经剪接组合。整支片不是由一个模型一次生成。
- comparison.mp4：原片在左、AI成片在右。两侧共享本轮旁白与配乐，便于比较画面；仅加版本标签，不是音频的前后对比。
- seedance-test.mp4：前一轮Seedance编辑对照，使用旧版配乐；与当前CapCut成片的音轨不同。真人和汤浪编辑素材原生834×1112后上采样到1080×1440，不能称为模型原生1080p。
- WebP图片：从对应实际视频抽帧，仅转换网页格式，未额外生成新人物。
- 全站CJ Logo：从当前品牌资产透明版原件直接复制，保留绿红配色、比例和图形，只用CSS控制显示尺寸。

展示用途为本章学习与实验。咖喱汤海、金碗与餐厅是视觉创意；AI摆盘和份量不代表实际出餐承诺。本次技术和画面检查通过，主观配音发音、口音与配乐听感仍需人工试听。After Effects是后续计划，不计入本次已完成步骤。没有新增角色、训练、脸部克隆或声音克隆。

本页没有提供开放商用或训练素材许可。工具生成额度与使用条件以各平台实际页面为准；本次CapCut所选声音已免费正常导出，不表示平台全部功能免费。
